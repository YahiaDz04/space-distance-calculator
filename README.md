# مِرقاب — حاسبة المسافات الفضائية

تطبيق ويب عربي للتعلّم عن المسافات بين الأرض والنجوم.

## الميزات
- البحث بالاسم العربي أو الإنجليزي أو مُعرّف HIP.
- فهرس من 1000 مدخل: 50 اسماً شائعاً بمسافات تقريبية و950 مُعرّفاً فهرسياً إضافياً.
- تحويل بين السنة الضوئية والكيلومتر والوحدة الفلكية والفرسخ الفلكي.
- تقدير الزمن النظري للسير على الأقدام والدراجة النارية والسيارة والطائرة ومركبة فضائية بسرعة مفترضة.
- واجهة عربية متجاوبة.

## التشغيل
ضع `index.html` و`stars.json` في المجلد نفسه. الأفضل استخدام GitHub Pages أو خادم محلي لأن بعض المتصفحات تمنع تحميل JSON عند فتح HTML مباشرة.

## تنبيه علمي
سرعات المركبات افتراضات تعليمية، والزمن الناتج لا يعني أن الرحلة ممكنة عملياً. المسافات تقريبية؛ المعرّفات التي لا تتوفر لها مسافة مدمجة تُترك فارغة بدلاً من اختلاق قيمة. لا يوجد اتصال مباشر بقاعدة بيانات فلكية.
